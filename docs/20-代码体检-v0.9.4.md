# 代码体检报告 —— v0.9.4（2026-11-04）

> 范围：`开发资料/src`（前端 1 个 356 KB 的 app.js + 后端 23 个模块）与 `docs/`。
> 方法：静态扫描（函数/监听器/IO/死代码/契约透传）+ 本轮 0.9.0–0.9.3 的实际故障复盘。
> 结论：**功能面可用，但“单文件 + 全局可变状态 + 手写契约”三件事已经到临界点**——本周期 4 个线上级 bug（镜牢→编辑空白、模板复用错位、搜索不刷新、同步复制）全部源自这三处，而不是源自业务逻辑本身。

## 二、问题清单（按优先级）

### P0 —— 会在 1.0.0 前变成事故

**2.1 前端单文件 + 全局可变状态（架构级）**
- `app.js` 里 `S` 有 60+ 字段，任何视图都直接读写；`render()` 用 innerHTML 整页重建，于是产生了 `refocus()`、`pRestoreScroll`、`imeComposing`、`suppressClick` 等**一串补丁**。
- 本周期故障直接证据：`S.editKind` 被镜牢复用 → `/api/edit` 页空白（0.9.3）；全页重建 → 输入法被打断（v0.8.5）；整页重建后 scrollTop 归零（批 1）。
- 建议：拆成 `store.js`（唯一写入口 + 订阅）、`views/*.js`（各自只读渲染）、`patch.js`（局部更新），`render()` 只负责“当前视图”的挂载。

**2.2 事件监听器散落，存在重复处理风险**
- 7 个 `click`、6 个 `keydown`，其中多个是捕获阶段；此前“×删不掉 / 点选与拖拽互相吞”“carry 状态下重复落块”都源于此。
- 建议：收敛为 1 个 `click` 委托 + 1 个 `keydown` 路由表，其余场景用局部 `addEventListener` 并在卸载时移除。

**2.3 后端单文件 101 路由，入参无 schema**
- `api.mjs` 1,237 行；每个 handler 自行 `body.x || ...`，字段改名/漏传都只能靠人眼（本轮 `argCounts`、`aliasOf` 未透出就是这样漏的）。
- 没有请求超时与并发保护：`md apply-all`、366 MB 快照属同步重活，界面会“转圈几秒无反馈”。
- 建议：按域拆 `routes/{mods,personality,skill,passive,buff,md,pick,system}.mjs`；给每个路由加 `schema`（字段/类型/必填），统一校验与错误码。

**2.4 死代码 12 个**
`fieldRow`、`pSinSelect`、`openSourceModal`、`renderModuleForm`、`mbSlotType`、`mbSetLoop`、`mbMissingRequired`、`mbRowByName`、`mbInsideLoop`、`openSlotPicker`、`mbSaveProps`、`schedulePDesc`。
其中 `openSlotPicker` 是被“就地输入”取代、`renderModuleForm` 是被画布取代、`mbMissingRequired` 是被 `mbMissingInfo` 取代——**留着会误导下一位维护者**，直接删。

**2.5 未保存保护不完整**
`beforeunload` 只有 1 处；模块画布有 `mbGuardDirty` 切页拦截，但人格/技能/被动/Buff **切页不拦截**（只有面板上的“已保存/有改动”文字）。

### P1 —— 影响可维护性与性能

**2.6 三套 normalize + 四套定时器**
`pNormalizePersonality/Skill/Passive/Buff` 各写一遍；`pDescTimer/pMetaTimer/pInfoTimer/buffFieldsTimer` 各自 450/700/400/500ms。
建议抽象 `fieldEditor({normalize, save, fields})`，定时器统一为 `debounce(ms)` 工具。

**2.7 魔法数字四处散落**
`450 / 700 / 900 ms`、`20000` 字符、`999` 上限、阈值 `9` 档、立绘 `12 MB`、`MAX_BODY 64 MiB`。
建议集中到 `src/constants.mjs`（前后端各一份，注释说明依据）。

**2.8 前后端契约手写映射**
`GET /api/buff`、`/api/skill` 里逐字段手拼 `fileInfo`；新增字段忘了就静默丢失。
建议：服务端返回“整份实体 + 派生字段”，前端用 `pick()` 取；或加契约测试（见 2.10）。

**2.9 服务端全同步 fs**
`readFileSync/writeFileSync` 遍布 `lethe/*`；单用户可接受，但大 Mod 的 `save`/`snapshot` 会阻塞事件循环数秒（UI 无进度条）。
建议（可选）：长任务改 `fs/promises` + 进度事件，或至少在前端显示“处理中”遮罩。

### P2 —— 加分项

**2.10 测试缺口**：8 组单测只覆盖基础设施；本周期 4 个 bug 全靠人眼发现。建议 `npm run smoke`（18 条 CDP 断言）+ `api-contract.test.mjs`（用沙箱私服跑 20 条读写）。
**2.11 文档索引**：docs 已到 19 篇，缺 `docs/README.md` 目录页与“当前生效约定”摘要。
**2.12 版本号双写**：已由 `tools/bump.mjs` 消除手工风险（本轮已落地）。
