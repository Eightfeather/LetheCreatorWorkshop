## 1. 这是个什么项目

**The Lethe Workbench（边狱工作台）**：面向《边狱公司》私服 **Lethe** 的 Mod 编辑器。
桌面形态为「单文件 exe（WebView2 壳）+ 内嵌 Node 后端」，前端是原生 DOM 单页应用。

能做到的事（截至 0.9.19）：

| 区域 | 能力 |
| --- | --- |
| Mod 管理 | 列表（可拖动排序）、启用/禁用、备份与版本回滚、永久删除（冷静期）、DLL 管理 |
| 人格编辑 | 罪人分栏、稀有度/血量/抗性/混乱阈值、立绘导入、技能与守备、被动分档、词条、源码页 |
| 技能编辑 | 预览卡（三层图标）、基础信息、硬币、描述、**置入区（模块块/未识别块/内置脚本块）** |
| 被动 / Buff 编辑 | 基础信息、条件（拥有/共鸣，互斥）、脚本置入、描述、文件字段 |
| 模块编辑 | Scratch 式积木画布（时点帽 / 遍历 / IF / 效果 / 获取 / 值块），输出代码页 |
| 镜牢编辑 | 卡包/饰品/战斗/敌人/普通敌人/敌人部位六张表 + 挑选器 + 批量落地 |

**不做**：战斗编辑与敌人编辑页（大纲里列为待做）、Mod 导入（占位）。

## 4. 首次搭建（照着敲）

```powershell
cd 编辑器正式稿\开发资料

# 1) 依赖（esbuild / postject）
npm install

# 2) 单元测试（不依赖游戏、不依赖私服）
npm test                      # 期望：通过 42 · 失败 0

# 3) 生成一个最小沙箱私服（造测试数据，不碰真实私服）
node tools\make-sandbox.mjs --out D:\tmp\lcw-sandbox --force

# 4) 起一个开发服务看界面（浏览器打开 http://127.0.0.1:3210 ）
node src\cli.mjs serve --root "D:\tmp\lcw-sandbox\BepInEx\plugins\Lethe" --port 3210

# 5) 打后端（Node SEA 单文件）
npm run build:server          # 产物 dist\server\LetheWorkbenchServer.exe

# 6) 打桌面壳（需要 dotnet SDK；会自动 dotnet restore）
npm run build:app             # 产物 dist\app\TheLetheWorkbench.exe，并复制到 编辑器正式稿\ 根目录
```

> **`--root` 既支持 `--root=路径` 也支持 `--root 路径`**（0.9.19 修）。
> 沙箱默认目录用 `--out` 指定；`npm test` 用的沙箱是自带临时目录，不会污染。

**构建耗时**：`build:server` 约 30–60 s（esbuild + SEA 注入），`build:app` 约 20–40 s（dotnet 编译）。

## 5. 开发循环（改一处前端 → 看到效果）

1. 起服务：`node src\cli.mjs serve --root=<沙箱> --port 3210`；
2. 浏览器打开 `http://127.0.0.1:3210`（token 会自动注入页面）；
3. 改 `src/web/app.js` / `style.css` → **刷新页面**即可（服务直读磁盘文件）；
4. 改后端 `src/**.mjs` → 重启服务（CJS/ESM 无热重载）；
5. 满意后：`npm run build:server` → 关掉占用 exe 的进程 → `npm run build:app`。

> 注意：`app.js` 会被 **打进 server payload**（`build-server.mjs` 把 `src/web` 内联进后端）。
> 所以只跑 `build:app` 不带上前端改动 —— 必须 `build:server` → `build:app` 两步。

**构建前自检（强烈建议）**：

```powershell
node --check src\web\app.js
node --check src\server\api.mjs
```

`build-server.mjs` **不做语法校验**，坏代码会被静默打包（历史踩过：`async` 与 `function`
被拆开，包出来的 exe 一打开就坏）。

## 6. 桌面壳（exe）怎么组装

```
build-server.mjs  →  src/web + data/*.json + 字体(ttf/woff2) 内联 → esbuild bundle
                  →  sea-prep.blob → postject 注入 node.exe → dist/server/*.exe
build-app.mjs     →  gzip 后端      →  build/payload/server.exe.gz
                  →  拷 WebView2 三个 DLL（Core/WinForms/Loader）
                  →  dotnet restore + build host（net48）→ dist/app/TheLetheWorkbench.exe
                  →  自动复制到项目根 TheLetheWorkbench.exe
```

运行期写入位置：`%LOCALAPPDATA%\LetheWorkbench\`（`config.json`、`logs\server.log`、
`runtime\<签名>\`、`webview2\`）。删掉该目录＝恢复出厂设置。

**为什么要内嵌字体**：`src/web/fonts/game.ttf`（23.8 MB，游戏中文）会被 base64 内联，
exe 因此从 ~22 MB 涨到 ~54 MB。仓库里这份是**构建输入**，不是让用户重复下载。

## 7. 调试界面（CDP）

宿主是 WebView2，可用 Chromium DevTools 协议直接驱动：

```powershell
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9440'
Start-Process 'E:\辅助文件\Mod编辑器\编辑器正式稿\TheLetheWorkbench.exe'
# 启动与后续驱动必须写在同一次 pwsh 调用里（进程随调用结束被回收）
```

要点：
- **端口冲突**：9410 常被 QQ/QQNT（`QQEX.exe`）占用 → 用 9440 以上；先 `netstat -ano | findstr :9440`。
- `app.js` 是 ES 模块，内部函数**不在 `window`**；只能点 UI 或读 `window.__WBS` 状态。
- 截图取景：元素 `getBoundingClientRect()` 给 `Page.captureScreenshot.clip`，`scale` 用 4/6/8。
- 跑 `npm run smoke` 前需要先构建 exe（它按 exe 启动并断言 18 条）。

## 8. 常见坑（都是真踩过的）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 补丁脚本报「锚点找不到」 | PowerShell here-string 按 ANSI 写中文，落盘变成 `?` | 用 UTF-8 写 `.cjs`（`write` 工具 / node 生成），别用 PS here-string |
| 补丁把文件改坏但构建「成功」 | `build-server.mjs` 不校验语法 | 每次改完先 `node --check` |
| exe 起来没有界面 / 报 `0x8007139F` | 残留 `msedgewebview2.exe` 占着 UDF | 任务管理器结束 `msedgewebview2` 再启动 |
| 改完前端但界面没变 | 只跑了 `build:app` | 必须 `build:server` 再 `build:app` |
| 配置丢失 / 指向错目录 | `config.json` 被 PowerShell 带 BOM 写入 | 用 node `writeFileSync(..., 'utf8')` 写 |
| 宿主杀不掉、exe 复制失败（EBUSY） | 上一次的进程还活着 | `Stop-Process TheLetheWorkbench,TheLetheWorkbenchServer` |

## 9. 关键代码地图

| 想改 | 去哪 |
| --- | --- |
| 界面（所有渲染与交互） | `src/web/app.js`（单文件 ~40 万字符；按 `renderXxx` 命名检索） |
| 样式 | `src/web/style.css`（尾部按 `@区块名:start` 追加，便于定位） |
| 接口 | `src/server/api.mjs`（`createApi()` 里 `'METHOD /api/xxx': handler`） |
| 鉴权/静态/启动 | `src/server/index.mjs`（`/api/health` 免 token，其余要 `x-wb-token` + Host/Origin） |
| 读写 Mod 文件 | `src/atomic.mjs`（事务写：tmp→备份→rename→回滚）、`src/safety.mjs`（路径/名字校验） |
| 技能/被动/Buff 写盘 | `src/lethe/apply.mjs`（`saveSkillFields` / `savePassiveFields` / `saveBuffFields` / `saveCompiled*`） |
| 脚本字符串 ↔ 积木 | `src/lethe/program.mjs`（编译）、`program-parse.mjs`（反向解析） |
| 时点 / 命令 / 词表 | `src/knowledge/*`（`timings.mjs`、`modular-tables.mjs`、`scopes.mjs`、`arg-counts.mjs`） |
| 镜牢六张表 | `src/lethe/mdtables.mjs`（+ `picker.mjs` 挑选器） |
| 备份 / 快照 / 撤销 | `src/lethe/{backups,autosave,snapshot,session}.mjs` |
| 宿主（C#） | `host/*.cs`（`Payload` 解包、`ServerRunner` 起后端、`MainForm` 载 WebView2） |

**两条硬规则**：
1. 写盘一律走 `writeFilesTransactional`（原子 + 备份 + 失败回滚），不要直接 `writeFileSync` Mod 文件；
2. 用户路径必须过 `cleanName` / `resolveInside`，不要拼字符串。
