## 八、教训（写给接手人）

1. **不要用 PowerShell here-string 写含中文的 JS**：PS 5.1 按 ANSI 读，会把中文变成 `?` 或乱码，
   表现为「锚点找不到」。一律用 `write` 工具（UTF-8）或 node 脚本生成 `.cjs` 再执行。
2. **补丁脚本必须断言锚点唯一**：`if (!s.includes(a)) throw`，并且改完立刻 `node --check`。
   `build-server.mjs` 不做语法校验，坏代码会被打进 exe（0.9.37 踩过）。
3. **一次改动一提交**：出问题能 `git revert`，不用写反向补丁（0.9.3 那次回退就是没有提交点，
   只能手写反向补丁，花了一小时）。
