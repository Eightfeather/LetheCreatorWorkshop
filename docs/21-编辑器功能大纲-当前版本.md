## 一、主页 【已一致】

- 左上：封面区（占位渐变 + "THE LETHE WORKBENCH" + 一句话说明）。
- 右上：四个圆形按钮 —— 设置（可用）、指南（占位：该功能正在维修）、封面（占位）、鸣谢（占位）。
- 右上其余空间：公告栏（占位，后续放版本更新公告）。
- 右下：名片 + 4 个导航键（主页 / Mod 管理 / Mod 编辑 / Mod 导入）。
  - 名片 5 格：编辑者（设置里可改，默认「但丁」）、编辑器名（边狱工作台 Limbus Workshop）、Mod 数量（含禁用、不含备份）、DLL 数量、所有 Mod 总体积。
  - 排布：10 列 × 3 行网格；上排「名字 4 + 留空 2 + Mod 数 2 + DLL 数 2」，下排「编辑器名 6×2 + 总体积 4×2」。
- 底部：导航行（主页/Mod 管理/Mod 编辑/Mod 导入/镜牢编辑）+ 状态行（私服路径、当前 Mod、保存状态、自动快照时间、版本号）。

## 二、Mod 管理 【已一致】

- 左栏「已加载 MOD（N / M）」：每项显示 Mod 名、人格数、文件数、体积；禁用项灰化并带右下红叉；支持指针拖拽调整顺序（只影响编辑器显示顺序，不影响游戏加载）。
- 右栏「已加载 DLL（N / M）」：`.dll` / `.dll.disabled` 列出，可切换启用；带备份与版本页签。
- 中栏：默认空；选中后显示详情（路径、类目、统计、人格预览），下方三按钮平均排列：
  - 启用（绿，已启用时置灰）、备份（黄，默认名「原名+年月日」，同日自动 `_2`）、禁用（红，已禁用时置灰且连点 3 次可进入永久删除）。
- 备份后，详情上方出现版本页签（当前 + 各备份），备份只读，需「替换」互换当前版本与备份（互换前弹确认，列出两个实际文件夹名）。
- 永久删除：弹窗列出将删除的 5 类位置，带冷静倒计时（可在设置里关/改秒数），确认后删除本体 + 用户备份 + 自动快照 + 流水 + 编辑器内工程数据。

## 四、模块编辑 【部分待做】

当前形态（一个页面）：
- 未选中模块时是**模块列表**：每行「模块名 + 用途徽标（被动/技能/Buff/通用）+ 积木数 + 测试标记」，底部「＋ 新建模块」；点击某行进入画布。
- 进入画布后是**积木画布**：
  - 工具栏：返回、模块名、前缀（时点）下拉、用途徽标、属性、查看输出代码、清空、撤销、重做、保存模块。
  - 左栏调色板：竖排分类「时点 / 目标 / 效果 / 获取 / IF / VALUE / Buff」，下方搜索框 + 可拖拽条目。
  - 中栏画布：`⚑ 当…时` 帽子（含面/暴击/关键词/按键实参）、`↻ 遍历` 块、效果函数块、`如果/如果不/继续如果` 条件块（可 + 条件，逻辑 无/AND/OR/XOR），任意层嵌套，右下角垃圾桶删除。
  - 画布下方：输出脚本预览（每时点一行，`Modular/…`）。
  - 「查看输出代码」当前是画布内整页面板，每行可手改并锁定对应积木。

**【待做】按大纲要改的部分**：
1. 拆成两页：**模块列表页** → 点进**积木画布页**（现在是同页切换，视觉上已接近，但列表页信息与入口要独立化）。
2. 工具栏「查看输出代码」改成**整页 VSCode 式**（当前为面板式），并保留"手动修改后锁定对应行积木"的行为（已具备行级锁）。
3. **遍历**从「目标分类里的块」改为**时点帽子右侧的遍历胶囊槽**，每个时点一个（现在遍历是块，规则是"同时点只能一个"）。
4. 实参就地输入：**回车提交、失焦不提交、空输入=取消**（现在是 blur 也提交）。
5. 「原版模块（官方控件）」大类：**先放着**，写入交接文档。

## 六、被动编辑 【已一致】
